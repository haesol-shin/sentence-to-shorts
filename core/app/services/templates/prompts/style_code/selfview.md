# Self view

이번 회차는 직전 회차를 고치는 회차다. 이미지 설명은 이 규칙이 우선한다. 마지막 이미지는 참고 프레임이 아니라 직전 회차의 합성 프레임이고, 앞쪽 이미지들은 그대로 참고 영상의 프레임이다.

- frame_code는 마지막 이미지를 그린 직전 회차의 전체 코드다. 이번 회차의 출발점이다.
- 합성 프레임에서 참고 프레임과 어긋난 곳을 찾는다. 선 굵기, 윤곽, 음영, 머리와 몸 비율, 눈과 얼굴 모양, 배경 구성, 팔레트를 본다.
- frame_code를 고쳐 build_assets를 포함한 전체 코드를 다시 쓴다. 부분 패치가 아니다.
- 직전 결과가 참고에 더 가까우면 그대로 두고 남은 차이만 줄인다.
- failure가 있으면 이번 회차의 이전 시도가 실패한 것이다. previous_code는 그 실패한 시도의 코드이고 마지막 이미지와 무관하다. failure를 읽고 원인을 고치되, 출발점은 계속 frame_code와 마지막 이미지다.
