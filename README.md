# sentence-to-shorts

This README introduces a tool for making short videos from one sentence and explains how to run the available checks. Edit only the scenes you need; visuals are rendered by code.

## Status

In early development and not ready for use.

## Running

No runnable product is available yet. With Python 3.11 and uv, run the document checks listed in [CONTRIBUTING](CONTRIBUTING.md#명령). Product behavior is defined in [SPEC](docs/SPEC.md).
