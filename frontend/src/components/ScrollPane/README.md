The overflowing column hides the scrollbar, keeps wheel, trackpad and keyboard scrolling, shows a 44 round jump control named by the caller (the gallery passes 「아래로 넘기기」) only while more content waits below, and moves one screen's 80 percent. In the app the control has its own dock row under the column, so it never covers content; a screen whose floating action covers the pane's bottom row sets `--scroll-pane-floor` to that row's height. Outside the app the dock has no height and the control floats over the column.
