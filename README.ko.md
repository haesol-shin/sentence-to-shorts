# sentence-to-shorts

이 README는 한 문장으로 짧은 영상을 만들고 필요한 장면만 고치는 도구의 소개와 실행 안내입니다. 화면은 코드로 렌더링합니다.

## 개발 상태

초기 개발 중이며 아직 사용할 수 없습니다.

## 실행 안내

제품 실행물은 아직 없습니다. 개발 문서 검사는 Python 3.11과 uv가 있는 환경에서 [기여 안내의 명령](CONTRIBUTING.md#명령)으로 실행합니다. 제품 동작은 [SPEC](docs/SPEC.md)에 있습니다.
