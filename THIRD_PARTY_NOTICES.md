## FFmpeg corresponding source

Distributions carry an FFmpeg executable taken from a pinned upstream build. It is built with `--enable-gpl --enable-version3`, so it is licensed GPL-3.0-or-later. The license text is in the `licenses` folder.

The complete corresponding source for every shipped executable is attached to the same Release as the distribution, as an asset named `ffmpeg-corresponding-source-<platform>.tar`. The asset contains the exact FFmpeg revision, the source archives for the external libraries enabled in the build, the builder release's scripts, patches and configuration, a copy of `ffmpeg-sources.lock.json`, and `SOURCE-README`. That README maps the executable to the archives and explains how to rebuild it. Every archive is checked against its pinned byte count and SHA-256 when the asset is made. The Release assets stay available for at least three years after publication.
