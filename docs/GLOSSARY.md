# 용어

이 문서가 용어의 원본이다. 문서와 코드와 대화는 같은 말을 같은 뜻으로 쓴다. 용어는 한국어와 영어를 병기한다. 아래 코드 필드 경계는 [SPEC](SPEC.md)을 맞추기 위한 기술 정리다.

## 제작 단위

- **프로젝트 (project)**: 같은 제작 설정으로 영상 여러 편을 만드는 단위다.
- **영상 (video)**: 한 편의 제작 상태와 결과를 묶는 단위다.
- **장면 (scene)**: 영상 안에서 부분 수정하는 단위다. 순서와 무관한 stable scene ID를 갖는다.
- **대사 줄 (line)**: 장면 안에서 음성과 자막을 연결하는 단위다. stable line ID를 갖는다.
- **revision**: 적용된 제작 상태의 버전이다.
- **snapshot**: 한 영상에 확정해 저장한 설정과 장면 상태다.
- **artifact**: 검증한 PNG, WAV, timing, 장면 clip, mp4 같은 생성 결과다.
- **피드 (feed)**: 프로젝트의 영상을 세로로 넘겨 보는 화면이다. 이번 MVP에서는 제외한다.

## 입력과 내용

- **주제 (topic)**: 사용자가 영상으로 만들려는 내용이다.
- **재료 (material)**: 대본의 근거로 쓰는 사용자 입력이다. MVP는 붙여넣은 글만 받는다.
- **참고 영상 (reference video)**: 형식과 스타일을 분석할 영상이다. 재료와 다르다.
- **소스 (source)**: 참고 영상과 재료를 묶어 부르는 말이다.
- **대본 (script)**: 영상 전체의 대사다. 사용자가 직접 넣거나 LLM이 쓴다.
- **화면 글 (display_text)**: 영상에 보이는 글이다.
- **말할 글 (speech_text)**: TTS가 읽는 글이다.
- **장면 데이터 (scene data)**: 모듈이 공유하는 typed JSON 계약이다. 장면, 대사, 설정, revision, artifact 참조를 연결한다.
- **출처 (origin)**: 값이 사용자 직접 입력, 참고 영상, 프리셋, 추천 중 어디에서 왔는지 나타낸다.

## 포맷과 스타일

- **포맷 (format)**: 스토리와 화면과 소리를 포함해 영상이 주는 인상 전체다.
- **포맷 카드 (format card)**: 이야기 틀, 화면 틀, 캐릭터 역할, 말투를 한 번에 채우는 기본값 묶음이다.
- **프리셋 (preset)**: 저장된 포맷이다. 설정과 스타일·템플릿 참조와 lock을 담는다. 주제, 대본, 장면, 생성 결과는 담지 않는다.
- **그림체 (art style)**: 머리, 몸, 소품, 배경을 그리는 형태 표현 규칙이다. 픽셀과 컷아웃은 기본 그림체다. 팔레트는 테마가 소유한다.
- **스타일 (style)**: 저장과 재사용의 문맥에서는 기본 그림체 또는 생성 그림체의 package를 뜻한다. 색과 글꼴만 바뀐 것은 새 스타일이 아니다.
- **테마 (theme)**: 그림체 안의 배경 선택, 대화창·자막 상자 모양(skin), 색 팔레트(palette) 설정이다.
- **화면 틀 (layout)**: 제목, 그림, 자막, 진행 표시가 놓일 자리와 구도다. 그림체의 형태와 다르다.
- **이야기 틀 (story structure)**: 대본의 시간상 진행 방식이다.
- **캐릭터 (character)**: 그림체 안의 부위 에셋을 조합한 인물이나 마스코트다.
- **캐릭터 역할 (character role)**: 캐릭터가 없거나 진행자이거나 장면 속 인물인지를 정한다.
- **말투 (register)**: friendly, neutral, casual 같은 대사의 언어 격식이다. 코드명은 register로 통일한다. tone 필드는 따로 만들지 않는다.
- **유머 (humor)**: 농담의 정도다. 말투와 별도 값이다.
- **템플릿 (template)**: 장면 데이터와 스타일을 화면으로 그리는 코드다. 생성 템플릿은 sandbox에서만 실행한다.
- **catalog**: manifest를 검증해 등록한 선택 가능 항목 목록이다.

## 소리와 자막

- **소리 (audio)**: 목소리, BGM, 효과음을 묶은 설정이다.
- **목소리 (voice)**: TTS 엔진과 모델 revision과 화자 설정의 조합이다.
- **BGM**: 영상 배경 음악이다. 내장 음원, 사용자 업로드, 코드 생성 loop를 입력으로 받는다.
- **코드 BGM**: LLM이 쓴 합성 코드를 sandbox에서 실행해 얻은 짧은 loop WAV다. 생성형 음악 모델과 다르다.
- **자막 설정 (caption settings)**: 표시 모드, 위치, 글꼴, 강조를 묶은 설정이다.
- **자막 표시 모드 (caption_mode)**: sentence, phrase, typewriter 중 하나다. 문서의 「자막 방식」은 이 표시 모드를 뜻한다.
- **timing artifact**: 확정 음성과 화면 글의 표시 시점을 연결한 결과다.
- **forced alignment**: 알려진 대본과 음성의 시점을 맞추는 작업이다. 참고 영상 전사와 다르다.

## 조작과 생성

- **세부 조정 (fine-tune)**: 기본값의 항목을 직접 바꾸는 조작이다.
- **고정 (lock)**: 프로젝트의 영상들에서 같은 값을 유지하는 설정이다.
- **변화 (variation)**: 영상마다 값이 달라질 수 있는 설정이다.
- **초안 (draft)**: 한 문장이나 카드 입력으로 채운 제작 설정과 대본 상태다.
- **대본 확인 (script confirm)**: 장면 정지 미리보기를 만들기 전의 사용자 확인이다.
- **장면 확인 (scene confirm)**: 실제 음성·렌더·조립을 시작하기 전의 사용자 확인이다.
- **렌더 (render)**: 장면 데이터를 화면으로 그리는 작업이다.
- **정지 미리보기 (still preview)**: 장면 구도를 확인하는 PNG다. TTS 전 timing은 예상값이다.
- **결과 재생 (result playback)**: 확정 timing을 사용한 mp4를 플레이어에서 보는 동작이다.
- **미리보기 (preview)**: 화면상의 검수 영역을 통칭한다. API와 시험에서는 정지 미리보기와 결과 재생을 구분한다.
- **생성 (generate)**: 대본부터 소리, 렌더, 조립까지 영상을 만드는 전체 과정이다. 수락 경로의 「실제 생성」은 장면 확인 뒤 실제 TTS·렌더·조립 실행이다.
- **다시 만들기 (regenerate)**: 변경 영향이 있는 장면이나 단계만 다시 실행하는 작업이다.
- **다음 영상 (next video)**: 기존 설정을 복사하고 주제와 대본을 비운 새 영상이다.
