# 0006 다섯 단계와 한 패널 UI를 사용한다

## Status

Accepted

## Date

2026-11-14

## Context

사용자는 한 문장으로 시작할 수 있어야 한다. 직접 선택과 대화가 서로 다른 제작 상태를 만들면 안 된다.

## Decision

흐름은 스토리, 시각, 장면, 소리, 생성의 다섯 단계다. 카드와 입력창은 같은 패널에 둔다. 별도 대화창은 두지 않는다. 첫 화면은 큰 입력창과 카드로 시작한다. 초안 뒤 입력창은 패널 아래에 고정한다. 입력창 위에는 현재 값 칩을 둔다. 데스크톱의 왼쪽 조정 패널과 오른쪽 9:16 미리보기는 제안이며, 편집 카드와 미리보기와 장면 선택의 위치와 폭은 SPEC 10a에 따라 디자인 시안 비교 뒤 정한다. 모바일은 같은 값을 세로 배치로 제공한다. 선택 화면 방문은 생략할 수 있다. 대본 확인과 장면 확인은 생략하지 않는다. 확인 조건에 해당하지 않는 단일 값 변경은 바로 적용한다. 적용 뒤 되돌릴 수 있다. 대본 재작성은 적용 전에 확인받는다. 여러 장면 변경도 적용 전에 확인받는다. 고정값 변경과 사용자 직접값 덮어쓰기도 적용 전에 확인받는다. TTS나 렌더를 다시 실행하는 변경도 적용 전에 확인받는다. 결과 화면에서 선택한 장면을 바로 고칠 수 있다.

## Basis

- Team decision: 다섯 단계와 미리 채운 기본값을 사용한다.
- Team decision: 카드와 입력창을 한 패널로 합친다.
- Team decision: 두 기기에서 같은 경험을 제공한다.
- Team decision: 대본과 장면 확인 뒤 실제 생성한다.

## Considered options

- 같은 패널의 카드와 입력: 직접 선택과 대화를 함께 제공할 수 있어 선택한다.
- 카드와 별도 대화창: 화면 복잡성이 늘어 선택하지 않는다.
- 다섯 화면 강제 통과: 자유로운 시작과 결과 수정을 막아 선택하지 않는다.

## Consequences

- 대화와 카드가 같은 typed 값을 갱신해야 한다.
- 390px와 1440px에서 같은 수락 경로를 시험해야 한다.
- 키보드가 입력창과 다음 행동을 가리지 않는지 확인해야 한다.
