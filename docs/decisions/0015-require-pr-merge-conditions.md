# 0015 PR 병합 조건을 공통 규칙으로 둔다

## Status

Accepted

## Date

2026-11-14

## Context

저장소 규칙은 모든 기여자에게 같은 기준을 제공해야 한다. 개인의 개발 도구는 저장소의 필수 조건이 아니다.

## Decision

변경은 짧은 브랜치의 PR로 제출한다. 필수 CI check가 모두 통과해야 한다. cubic 지적은 수정하거나 근거를 들어 답변해야 한다. 해결하지 않은 지적을 남긴 채 병합하지 않는다. 병합 방식은 squash다. 자동 병합도 같은 조건을 따른다. 기여자가 사용하는 개발 도구는 제한하지 않는다. 결정이 바뀌면 새 ADR을 추가한다.

## Basis

- Team decision: 개인 작업 방식과 저장소 운영을 분리한다.
- Team decision: CI 통과와 cubic 지적 해결 또는 답변을 PR 병합 조건으로 둔다.
- Team decision: 짧은 브랜치와 squash와 Conventional Commits와 변경 ADR은 도구와 무관한 공통 규칙이다.

## Considered options

- 도구와 무관한 병합 조건: 모든 기여자에게 적용할 수 있어 선택한다.
- 개인 실행 도구를 저장소 필수 요건으로 사용: 팀 공통 운영과 달라 선택하지 않는다.
- 자동 병합에 검사 예외 허용: 같은 품질 기준을 보장하지 못해 선택하지 않는다.

## Consequences

- 공개 기여 안내와 PR 템플릿과 CI는 같은 조건을 사용해야 한다.
- 봇 응답 자체를 지적 해결로 간주하면 안 된다.
- 개인 실행 절차는 공개 저장소에 포함하지 않는다.
