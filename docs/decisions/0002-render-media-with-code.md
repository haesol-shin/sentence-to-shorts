# 0002 영상은 코드로 렌더링한다

## Status

Accepted

## Date

2026-11-14

## Context

전체 영상을 다시 만들면 변경하지 않은 장면까지 달라질 수 있다. 사용자는 원하는 장면만 고칠 수 있어야 한다.

## Decision

생성형 이미지 모델과 영상 모델과 음악 모델을 쓰지 않는다. LLM은 대본과 장면 데이터 JSON을 만든다. 템플릿 코드가 그림을 그린다. 기본 그림체는 픽셀이다. 새 스타일과 템플릿은 코드로 만들고 저장해 재사용한다. 캐릭터는 부위 에셋을 조합한다. 바뀐 장면만 다시 만든다. 출력 영상에는 앱 이름과 워터마크를 넣지 않는다.

## Basis

- Team decision: 생성 모델 대신 코드 렌더링을 사용한다.
- Team decision: 새 스타일의 형태를 수정할 수 있어야 한다.
- Team decision: 장면 단위 재생성과 저장 스타일 재사용을 제공한다.
- Team decision: 출력 영상에 앱 표시를 넣지 않는다.

## Considered options

- 코드 렌더링: 장면별 변경과 재사용을 제어할 수 있어 선택한다.
- 생성형 이미지·영상·음악 모델: 제품 범위에서 제외한다.
- 고정 스타일만 제공: 새 스타일 제작 요구를 충족하지 못해 선택하지 않는다.

## Consequences

- 생성 코드는 [sandbox 결정](0005-run-generated-code-in-pyodide-deno.md)을 따라야 한다.
- 스타일 검수는 색과 글꼴뿐 아니라 실제 형태 변화를 확인해야 한다.
- 장면별 artifact와 변경 범위를 관리해야 한다.
