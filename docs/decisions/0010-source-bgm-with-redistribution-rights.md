# 0010 재배포 가능한 BGM 출처를 제안한다

## Status

Proposed

## Date

2026-11-14

## Context

완성 영상에 음악을 쓰는 허가와 앱에 원본 음악을 묶는 허가는 다르다. 무료라는 표시만으로 번들 권리를 확정할 수 없다.

## Decision

OpenGameArt의 개별 CC0 곡을 우선 검토하도록 제안한다. 부족한 분위기는 Incompetech의 CC BY 4.0 곡으로 보충하도록 제안한다. 곡별 원본 페이지와 라이선스와 권리 증거를 보관하도록 제안한다. CC BY 곡은 앱과 출력 영상에 필요한 표시를 제공하도록 제안한다. Pixabay와 Uppbeat와 Mixkit와 YouTube Audio Library는 별도 재배포 권리를 확인하기 전 기본 번들에서 제외하도록 제안한다. 효과음은 Kenney의 개별 CC0 팩을 우선 검토하도록 제안한다.

## Basis

- [CC0 공식 설명](https://creativecommons.org/publicdomain/zero/1.0/)은 복제와 수정과 배포의 조건을 설명한다.
- [CC BY 4.0 공식 설명](https://creativecommons.org/licenses/by/4.0/)은 표시와 변경 고지 조건을 설명한다.
- [OpenGameArt FAQ](https://opengameart.org/content/faq)는 에셋별 라이선스 확인의 기준이다.
- [Incompetech FAQ](https://incompetech.com/music/royalty-free/faq.html)는 곡 사용과 표시 조건의 근거다.

## Considered options

- 개별 CC0와 CC BY 확인: 원본 배포 권리를 확인할 수 있어 제안한다.
- 무료 음원 사이트 전체 허용: 개별 권리와 번들 허가가 달라 선택하지 않는다.
- 앱 안 표시만 제공: 사용자 출력의 표시 의무를 대체하지 못해 선택하지 않는다.

## Consequences

- 출처를 골라도 개별 곡의 채택은 확정되지 않는다.
- 청취와 권리 증거 수집이 필요하다.
- CC0도 Content ID 청구가 없다는 보증은 아니다.
