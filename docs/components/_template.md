# 부품 명세 양식

- 언제 쓴다: 어떤 상황에서 이 부품을 고르는지 적는다.
- 언제 쓰지 않는다: 겉모양이 비슷해도 이 부품을 쓰지 않는 상황과 대신 쓸 부품을 적는다.
- variant: 정한 변형과 각 변형의 용도를 적는다. 지금 구현에만 있는 변형은 구분한다.
- 쓰는 토큰 / layer: [디자인 규칙](../../DESIGN.md)과 [역할 토큰](../../design/tokens/tokens.json)을 기준으로 쓰임과 겹침 순서를 적는다. 흐름 안에 있으면 별도 layer가 없다고 적는다.
- 쓰는 화면: 실제 쓰는 화면과 여는 조작을 적는다. 갤러리에만 있는 예는 제품 사용으로 세지 않는다.
- 갤러리 사례: 실제 `?case=` 주소를 저장소 상대 링크로 붙인다. 전용 사례가 없으면 그렇게 적고, 비교할 수 있는 예만 그 이유와 함께 링크한다.

출처가 다르면 해당 항목에 정본을 적고 바로 아래 `확인 필요` 줄에 서로 다른 출처와 현재 구현을 적는다. 정본이 없는 값은 미정이라고 밝히고 제안과 구현을 결정으로 쓰지 않는다.
