# 상단바

- 언제 쓴다: 첫 화면 뒤에 공통으로 쓰는 화면 틀이다. 왼쪽에는 되돌리기·다시 하기 아이콘을 두고 앱 이름을 반복하지 않는다. 가운데에는 단계 표시를 두며 지금 단계는 굵은 글자와 아래 5px 점, 지난 단계는 돌아갈 수 있게 표시한다. 오른쪽 끝은 영상 전체의 일에만 쓴다. 편집의 「영상 만들기」는 진행 중 같은 자리에서 「■ 만들기 멈추기」로 바뀌고 결과에서는 「mp4 저장」을 둔다.
- 언제 쓰지 않는다: 첫 화면에서는 상단바와 단계 표시를 두지 않는다. 컨셉·대본처럼 단계를 넘기는 행동은 작업 칸 아래 오른쪽의 단추 줄에 두고, 장면에만 걸리는 값은 편집의 「이 장면」에서 고친다. 편집 정본 B에서는 영상 전체 설정도 상단바 팝오버가 아니라 작업 칸의 「영상 전체」 탭에 둔다. 이전 기준선의 상단 「영상 설정」 팝오버는 이 편집 배치에서 대체됐다.
- variant: 정본 데스크톱은 흰 띠와 가운데 단계 표시를 유지한다. 영상 만드는 중에는 파란 고리 스피너와 진행 글자·숫자, 회색 화살표를 같은 자리에 두며 화살표가 있는 상태 단추로 [진행 창](dialog.md)을 연다. 진행 값 자체는 조작이 아니다. 지금 작은 화면에서는 단계 표시 대신 단계 메뉴를 쓰며, 이는 데스크톱의 단계 표시 규칙이 아니다. `TopBarItem`은 항목 트리거, `TopBarStatus`는 상태 트리거며 저장 실패 상태 판은 갤러리가 보여 주는 변형이다. 앱의 영상 진행 창은 상태 트리거를 재사용하되 별도로 조립한다.
- 쓰는 토큰 / layer: 데스크톱 띠는 높이 56px, 좌우 16px, 위 6px, 기본 묶음 간격 16px, 흰 `--surface`(=`--popover` `#FFFFFF`)를 쓴다. 단계 표시 높이는 `--size-control` 44px, 글자는 15px, 단계 간격 16px과 좌우 안쪽 14px, 지금 단계 점은 `--part-step-dot` 5px이다. 지난·지금 단계는 `--foreground`, 남은 단계와 진행 화살표는 `--sub`, 진행 스피너와 글자·숫자는 정본의 `--progress` `#1B64DA`다. 띠와 띠 안 진행에는 별도 겹침 층을 두지 않는다. 이름 메뉴는 메뉴 층, 갤러리 상태 판은 `--z-panel` 45, 앱의 진행 창은 막 45·창 46을 쓴다.
  - 확인 필요: [디자인 규칙](../../DESIGN.md#layout)의 높이 64px 표기와 달리 데스크톱 정본과 [현재 상단바](../../frontend/src/app/shell/top-bar.tsx)는 56px이다. 현재 `--layout-topbar-h` 64px은 작은 화면에서 쓰는 최소 높이로 유효하며, 데스크톱 높이로 쓰지 않는다. [디자인 규칙](../../DESIGN.md#elevation--depth)은 상단바를 sticky 또는 fixed로 기술하지만 현재 셸의 상단바는 일반 흐름에서 `relative`이다.
  - 확인 필요: [디자인 규칙](../../DESIGN.md#components)은 진행 스피너에 `--emphasis`, 글자에 `--progress`를 적는다. 영상 진행 기준선과 정본은 둘 모두 `#1B64DA`이며 현재 [TopBarStatus.css](../../frontend/src/components/TopBarStatus/TopBarStatus.css)도 둘 다 `--progress`를 쓴다. 정본의 일반 고리 스피너 16px과 현재 상태 트리거의 18px도 구분한다.
- 쓰는 화면: [앱 셸](../../frontend/src/app/shell/top-bar.tsx)이 컨셉·대본·편집·영상 만드는 중·결과에 쓴다. 현재 데스크톱의 왼쪽에는 되돌리기·다시 하기와 영상 제목 메뉴가 있다. 오른쪽에는 편집의 상태와 만들기·멈추기, 결과의 자막 저장·mp4 저장이 있다. 제목은 영상 이름이며 앱 이름은 아니다.
  - 확인 필요: 편집 정본 B의 「영상 전체」 탭이 이전 기준선의 「영상 설정」 팝오버를 대체했지만, 현재 셸은 편집과 결과에 [VideoSettings](../../frontend/src/app/shell/video-settings.tsx) 트리거와 팝오버를 여전히 그린다. 지금 장면 패널의 탭도 정본의 「이 장면」·「영상 전체」 범위 탭과 다르다.
  - 확인 필요: 기준선은 컨셉과 대본 상단바의 오른쪽 끝을 비운다. 현재 앱은 대본에서는 그 단추를 두지 않지만 컨셉에는 비활성 `NextAction` 자리를 남긴다. [제품 명세](../SPEC.md#2-흐름)는 네 단계다. 정본에는 상단바 표시 수 3·4가 미정으로 남아 있어 제품 흐름과 표시 수를 구분한다. [현재 데스크톱 앱](../../frontend/src/app/shell/stage-nav.tsx)은 세 탭을 쓰고 결과에서도 편집을 현재 단계로 보이며, 작은 화면 메뉴와 갤러리 단계 표시는 네 단계를 보인다.
- 갤러리 사례: [항목 기본](../../frontend/src/gallery/index.html?case=32-1-default), [항목 메뉴 열림](../../frontend/src/gallery/index.html?case=32-7-menu-open), [현재 단계](../../frontend/src/gallery/index.html?case=34-1-current), [지난 단계](../../frontend/src/gallery/index.html?case=34-2-past-default), [저장 실패 판 예](../../frontend/src/gallery/index.html?case=33-7-panel-open), [진행 판 열림](../../frontend/src/gallery/index.html?case=33-8-working-open). 전체 상단바 조립이나 편집 정본 B의 범위 탭 전용 사례는 아니다. 「영상 설정」이 적힌 항목 사례는 트리거의 모양을 보여 줄 뿐 편집 정본의 배치를 뜻하지 않는다.
